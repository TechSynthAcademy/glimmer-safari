# Glimmer Safari

A calm 3D collectathon built with [Three.js](https://threejs.org). Walk a golden-hour meadow and pocket 21 glowing glimmers — each one named after a SAFE TO RESHAPE Viral 21 practice.

## Play

Open `index.html` in a browser, or visit the Vercel deployment once it is live.

## Controls

| Input | Action |
| --- | --- |
| **W A S D** | Walk |
| **Mouse drag** | Look around |
| **Space** | Jump |
| Walk into a glimmer | Collect it |

## Stack

- Three.js r160 (CDN, no build step)
- Static HTML + CSS
- Deployable on Vercel as a static site

## Theme

SAFE TO RESHAPE — joy, safety, and tiny practices you can pocket.
